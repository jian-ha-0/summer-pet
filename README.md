# 夏日宠物 - 桌面日志提醒助手

一只可爱的夏日主题桌面小海豚，陪你工作学习，定时提醒记录日志。

## 功能

- **桌面宠物**：一只蓝色小海豚，带有海浪和太阳动画，悬浮在桌面角落
- **日志记录**：记录每天的心情、工作、感想，支持心情标签和自定义标签
- **定时提醒**：按设定间隔弹出提醒，根据时间段智能切换提醒语
- **日志管理**：查看历史日志、统计数据、删除日志
- **托盘常驻**：最小化到系统托盘，不打扰工作

## 快速开始

```bash
# 安装依赖
npm install

# 启动
npm start
```

## 打包

```bash
npm run build
```

## 使用说明

1. 启动后宠物出现在屏幕右下角
2. **点击宠物**：弹出菜单（写日志/查看日志/设置/隐藏）
3. **右键宠物**：同样弹出菜单
4. **拖拽宠物**：按住拖拽到任意位置
5. **托盘图标**：双击显示宠物，右键打开菜单
6. **日志窗口**：选择心情表情，填写内容，添加标签，保存

## 设置

- 提醒间隔：15~180 分钟可调
- 提醒开关：随时开启/关闭
- 位置记忆：宠物位置自动保存
