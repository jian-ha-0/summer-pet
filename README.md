# 夏日宠物 - 桌面日志提醒助手

一只可爱的夏日主题桌面小海豚，陪你工作学习，定时关心提醒，记录日志与计划。

## 功能

### 桌面宠物
- **精致海豚**：CSS 绘制的小海豚，带身体高光、阴影、尾巴摆动、眨眼、浮动动画
- **时间主题 UI**：根据当前时间自动切换 7 种主题（清晨/上午/中午/下午/傍晚/晚上/深夜）
  - 白天显示太阳 + 旋转光芒
  - 晚上显示月亮 + 闪烁星星
  - 背景色随时间渐变变化
- **光斑粒子**：6 个飘动的金色/蓝色粒子
- **多层海浪**：3 层 SVG 波浪动画
- **启动动画**：夏日主题启动画面，2.5 秒后自动关闭

### 交互
- **长按拖动**：长按窗口任意位置 200ms 后进入拖动模式
- **点击宠物**：触发随机互动反应（7 种：开心/害羞/惊讶/困倦/眨眼/跳舞/转圈），每种都有独特动画和话语
- **点击空白**：显示水平菜单（计划/日志/查看/设置/隐藏）
- **右键**：显示今日计划概览
- **水波纹**：点击时的扩散动画效果

### 关心提醒
- **120+ 条关心话语**：分 7 个时段 + 通用，涵盖喝水、休息、眼保健操、活动身体、吃饭、心情、睡眠等
- **智能触发**：每 40-70 秒随机弹出，80%概率用时段专属话语
- **时段感知**：清晨/上午/中午/下午/傍晚/晚上/深夜各有不同关怀重点

### 工作计划
- **添加计划**：内容 + 时间点 + 日期（今天/明天/每天）
- **计划列表**：按分组显示（今天/明天/每天/未来/过去）
- **今日概览**：进度条 + 快捷预览
- **到点提醒**：计划时间到达时自动弹出气泡 + 系统通知
- **完成标记**：点击圆点标记完成

### 日志记录
- **写日志**：选择心情表情（8 种）+ 文字内容 + 自定义标签
- **日志列表**：时间线布局 + 心情分布条形图 + 统计卡片
- **查看历史**：按时间排序，支持删除

### 系统托盘
- 双击托盘图标显示宠物
- 右键托盘打开快捷菜单

## 快速开始

```bash
# 安装依赖
npm install

# 启动
npm start
```

## 打包

```bash
npm run build
```

## 使用说明

1. 启动后宠物出现在屏幕右下角，先显示启动画面
2. **长按任意位置** → 拖动窗口
3. **点击海豚** → 随机互动（动画 + 话语）
4. **点击空白处** → 显示水平菜单
5. **右键** → 显示今日计划概览
6. **菜单** → 工作计划 / 写日志 / 查看日志 / 设置 / 隐藏

## 设置

- 提醒间隔：15~180 分钟可调
- 提醒开关：随时开启/关闭
- 位置记忆：窗口位置自动保存
